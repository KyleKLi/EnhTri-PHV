# Pretrained model

Download `Rostlab/prot_t5_xl_half_uniref50-enc` into:

```text
models/prot_t5_xl_half_uniref50_enc/
```

The directory must contain at least `config.json`, `pytorch_model.bin`,
`spiece.model`, `tokenizer_config.json`, and `special_tokens_map.json`.
Pretrained weights are not redistributed in this repository.
